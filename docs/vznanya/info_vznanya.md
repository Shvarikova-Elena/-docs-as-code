# ВЗНАНИЯ - международная образовательная платформа, созданная для преподавателей и школ, которые обучают в онлайн и офлайн формате

**На платформе вы можете:**

1. Работать 24/7 без необходимости в VPN;
2. Использовать конструктор из 53 механик для создания уроков;
3. Стимулировать интерес и разнообразить обучение с помощью игр;
4. Создавать задания с интерактивными видео: мультики, фильмы, клипы, выступления комиков;
5. Запускать увлекательные челленджи для учеников;
6. Задать упражнения на дом и быть уверенным, что ученик их действительно выполнит, а не спишет с решебника;
7. Не беспокоиться о проверке заданий, потому что на ВЗНАНИЯ встроена автоматическая проверка результатов, вся информация  по выполненным урокам/играм хранится в едином журнале.
