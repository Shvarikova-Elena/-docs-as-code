## Пользовательские сценарии

Данный раздел содержит:

- пользовательский сценарий приложения **Нотсапп**;
- диаграмму последовательности действий к данному сценарию, подготовленную с помощью **PlantUML**.

!!! note "Примечание"
    **Нотсапп** — это выдуманное мобильное приложение для пользовательских заметок. В Нотсаппе можно создавать, хранить и редактировать заметки.

## Примеры статей

Данный раздел содержит примеры статей к платформе **Взнания**.

При подготовке статей было подключено несколько плагинов:

1. **Плагин для создания тегов.** К статьям добавлены теги, которые выведены на отдельную теговую страницу.
2. **Плагин для окна поиска.**
3. **Плагин для создания галереи изображений** из добавленных в статьи рисунков, который позволяет увеличивать масштаб изображений.

Кроме того, в статьях был добавлен блок «Внимание» с использованием расширения `pymdownx.snippets`.
