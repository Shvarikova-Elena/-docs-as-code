# Регистрация ученика

**Для регистрации на платформе выполните следующие действия:**

Нажмите на кнопку **Зарегистрироваться**. Отобразится окно регистрации, в котором нужно заполнить все обязательные поля.

![Окно регистрации](../images/picture.jpg)

2. В поле «Кто вы?» выберите роль **Ученик**.
3. Заполните поля:
    * «Ваша фамилия»;
    * «Ваш E-mail»;
    * «Ваше имя».
4. Придумайте пароль и повтрите его в соответствующих полях. 
>Пароль должен состоять только из латинских букв и цифр. 
5. Поставьте галочку, подтверждающее согласие с условиями пользовательского соглашения.
6. Нажмите на кнопку **Зарегистрироваться**. После регистрации вы окажитесь в своем личном кабинете.
7. Введите код группы в специальное окно и активируйте его.
