# Пользовательский сценарий «Удаление заметки»

**Действующие лица:**
—	Пользователь
—	Приложение
—	Бэк
—	База данных

**Предварительные условия**

Пользователь должен находиться на главном экране.

**Выходные условия**

Заметка пользователя удалена из Системы.

**Основной сценарий**

1.	Пользователь выбирает заметку, которую хочет удалить.
2.	Приложение открывает заметку.
3.	Пользователь нажимает кнопку Удалить.
4.	Приложение отправляет запрос Бэку на удаление заметки.
5.	Приложение открывает пользователю уведомление «Удалить заметку?».
6.	Пользователь нажимает кнопку «Да!».
7.	Бэк удаляет заметку в Базе данных.
8.	Бэк возвращает Приложению ответ об удалении заметки.
9.	Приложение открывает пользователю уведомление «Заметка успешно удалена».

Альтернативный сценарий 1

1.	Пользователь выбирает заметку, которую хочет удалить.
2.	Приложение открывает заметку.
3.	Пользователь нажимает кнопку Мои заметки.
4.  Приложение открывает пользователю главный экран.


Альтернативный сценарий 2

1.	Пользователь выбирает заметку, которую хочет удалить.
2.	Приложение открывает заметку.
3.	Пользователь нажимает кнопку Удалить.
4.	Приложение отправляет запрос Бэку на удаление заметки.
5.	Приложение открывает пользователю уведомление «Удалить заметку?».
6.	Пользователь нажимает кнопку «Нет!».
7.	Приложение возвращает пользователя в заметку.
8.	Пользователь нажимает кнопку Мои заметки.
9.	Приложение открывает пользователю главный экран.
